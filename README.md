# VertDev

VertDev — программа для автоматического построения исполнительных схем
железобетонных конструкций по проектному DXF и геодезической съёмке.

Автор проекта: Lampochka
Код: ChatGPT - OpenAI, DeepSeek
Язык: Python
GUI: Tkinter
Основная библиотека DXF: ezdxf

------------------------------------------------------------
Назначение
------------------------------------------------------------

VertDev автоматизирует построение исполнительных схем пилонов,
стен, лифтовых шахт и лестничных клеток.

Программа анализирует проектный DXF, сопоставляет его со съёмкой
тахеометра и автоматически строит отклонения.

Главная цель проекта — максимально сократить время подготовки
исполнительной схемы.

------------------------------------------------------------
Основные возможности
------------------------------------------------------------

✓ автоматический поиск пилонов

✓ обработка стен

✓ обработка лифтовых шахт

✓ обработка лестничных клеток

✓ поиск соответствующих съёмочных точек

✓ расчёт отклонений

✓ построение стрелок

✓ подписи В / Н

✓ диагностика

✓ экспорт результата в DXF

✓ portable-версия программы

------------------------------------------------------------
Требования к проекту
------------------------------------------------------------

Проект должен быть экспортирован через ПБЛОК.

В DXF должны присутствовать только стены и пилоны.

Все конструкции должны быть замкнутыми полилиниями.

------------------------------------------------------------
Формат съёмки
------------------------------------------------------------

TXT

Имя, X, Y, Z

Например

1,130.342,160.533,164.432

------------------------------------------------------------
Использование
------------------------------------------------------------

1.
Экспортировать проект через ПБЛОК в DXF.

2.
Выбрать DXF.

3.
Выбрать TXT съёмки.

4.
Нажать "Построить".

5.
Открыть результат.

------------------------------------------------------------
Философия проекта
------------------------------------------------------------

VertDev создаётся не как ещё одна CAD-программа.

Его задача — автоматизировать рутинную работу инженера,
оставляя человеку только контроль результата.

Главный принцип разработки:

"Максимум автоматизации.
Минимум ручной работы."
