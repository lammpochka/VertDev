Версия 0.9.3
Дата: 11.07.2026

Первая стабильная рабочая версия VertDev.

Основные возможности
--------------------

- Автоматический поиск пилонов.
- Автоматический поиск стен, лестниц и лифтов.
- Интеллектуальное сопоставление съёмочных точек с конструкциями.
- Автоматический расчёт отклонений.
- Построение стрелок отклонений.
- Раздельные подписи:
    • значение отклонения;
    • отметка В/Н.
- Обработка неполных пилонов.
- Обработка стен по сегментам.
- Полилинии вместо отдельных линий стрелок.
- Экспорт результата в DXF.
- GUI с настройками и диагностикой.
- Portable-версия приложения.
- Сохранение настроек.
- Журнал диагностики.

Исправления
-----------

- Исправлена обработка пилонов, снятых с нескольких сторон.
  Теперь для каждого пилона автоматически выбирается одна сторона,
  исключая появление стрелок с разных сторон одной конструкции.

- Полностью переработан алгоритм обработки стен.

- Добавлена обработка лифтовых шахт и лестничных клеток.

- Исправлено множество ошибок сопоставления съёмки с проектом.

Известные ограничения
---------------------

- Секция должна быть ориентирована вдоль глобальных осей X/Y.
- Для корректной работы стены и пилоны должны быть экспортированы
  через ПБЛОК в отдельный DXF.
- Все стены и пилоны должны быть замкнутыми полилиниями.
- После построения может потребоваться вручную устранить
  пересечения обозначений с другими элементами чертежа.

-----------------------------------------
VertDev развивается по принципу:
"Максимум автоматизации, минимум ручной
работы инженера."
-----------------------------------------
## Автоматическое размещение длинных размеров
- Добавлена проверка обеих длинных граней веером лучей по контурам других пилонов.
- Для длинных размеров реализован поиск свободной текстовой области: сначала противоположная сторона, затем увеличение отступа шагом из настроек до заданного предела.
- В карту занятости добавляются отдельные области виджетов отклонений, торцевых текстов и уже размещённых длинных размеров.
- Если обе стороны недопустимы или свободное место не найдено, длинный размер всё равно выводится красным.
- Алгоритм пока применяется только к длинным сторонам; торцевые размеры остаются на прежнем фиксированном размещении.

## 1.8.11 — диагностика размеров
- Во вкладку «Диагностика» добавлен отчёт по каждому длинному и торцевому размеру: проектное значение, подписанные отклонения, среднее, диапазон рандома, выбранная поправка и итог.
- В журнал главной вкладки добавлены количество сгенерированных размеров и активный режим.
- Имя выходного DXF теперь содержит `_DOPUSK`, если включена «Генерация допуска», и `_FACT`, если выключена.

## 1.8.12 — исправлена привязка отклонений к размерам
- Длинный размер теперь определяет направление поправки по отклонениям торцов.
- Торцевой (короткий) размер теперь определяет направление поправки по отклонениям длинных сторон.
- Диагностика показывает именно те отклонения, которые используются для выбора поправки соответствующего размера.


## 1.8.13 — компактный интерфейс и управление размерами
- Добавлена галочка «Рисовать размеры на чертеже»; при отключении размерные сущности не создаются.
- Параметры размеров перенесены в отдельное компактное модальное окно.
- Главное окно больше не разворачивается автоматически на весь экран и открывается компактным, оставаясь изменяемым по размеру.
